# 対話型 LINE ボット自動収集システム (100% LINE完結・Notion不要・1Bot完結 MVP)

女性地下アイドルのライブ・イベント情報を自動収集し、LINEグループ内で**「今日新潟で何かある？」「7月12日東京である？」**と話しかけるだけで、その地域の日時情報に合致した最新のライブ一覧をその場で返信してくれる対話型ボットシステムです。

Notionなどの外部データベースは一切使わず、LINEの「通知」と「応答」のすべてを **1つのLINEボットアカウントだけで完結** させます！

---

## 🛠️ システムの仕組み (二刀流設計)

> [!NOTE]
> **LINE Notify 終了に伴う仕様アップデート (2026年最新仕様)**
> LINE Notify サービスは2025年4月1日に終了したため、本システムは最新の **LINE Messaging API (ボットアカウント) のみを用いて通知と対話の両方を行う最新仕様** にアップグレードされています。タクミさんが用意するアカウントは「1つのボットアカウントのみ」で良くなり、設定の手間が半分になりました！

1. **マークアイドルの「個別追跡」（自動プッシュ通知あり）**
   - 設定ファイル (`config.py`) に登録したお気に入りのグループ（初期値: `東京CuteCute`, `Redradiance`）は、タイムライン（X）やチケットサイトを巡回し、新着イベントやお礼ツイート（セトリ・チェキ写真等）があれば、**LINEボットがグループへ自動でプッシュ通知**します。
   - 無料プランの無料メッセージ枠（月200通）の中で完全無料で余裕を持って運用できます。
2. **エリア一般イベントの「網羅収集」（自動通知なし・DB蓄積）**
   - 「新潟 アイドル」などの一般的なキーワードでチケットサイトを巡回し、新潟や東京で開催されるすべてのアイドルライブ情報をローカルデータベース (`events.db` - SQLite) に自動で蓄積します。
   - 毎日数十件とある一般イベントで通知が嵐のようにならないよう、これらは自動プッシュ通知せず、データベースに静かに保存されます。
3. **対話型「一括引き出し」（LINE返信）**
   - スマホのLINEグループでボットに向かって**「今日新潟でなんかある？」**と聞くと、データベースから「マークしているグループ」と「その日の一般アイドルライブ」の両方を合算して、その場でまとめてリスト返信します！

## 📋 事前準備・セットアップ手順

### 1. LINE Messaging APIの準備 (ボットアカウントの作成)

「今日何かある？」という質問に対してその場で返答させ、新着を自動通知させるためのボットアカウントの作成です。

1. [LINE Developers](https://developers.line.biz/)にLINEアカウントでログインします。
2. **「プロバイダー」** を作成し、その下に新規チャネルとして **「Messaging API」** を作成します。
3. 作成後、以下の情報をコピーして控えます：
   * **チャネル基本設定** タブの最下部にある **「チャネルシークレット (Channel Secret)」**
   * **Messaging API設定** タブの一番下にある **「チャネルアクセストークン (長期)」** （なければ「発行」ボタンを押して生成します）
4. 同タブの「応答メッセージ」の設定項目で **「自動応答メッセージ」を無効（オフ）** にし、**「Webhook」を有効（オン）** にします。
5. このボットのQRコードをスマホで読み取り、お友達と共有している（または自分一人の）**LINEグループにこのボットアカウントを招待**します。

### 2. ローカル環境の構築手順

タクミさんのPC上で動作テストを行うための手順です。

#### ① 依存パッケージのインストール
1. 本プロジェクトのディレクトリに移動します：
   ```bash
   cd C:\Users\takum\.gemini\antigravity\scratch\idol-event-collector
   ```
2. 必要なPythonライブラリをインストールします：
   ```bash
   py -m pip install -r requirements.txt
   ```
3. Playwrightのブラウザをインストールします：
   ```bash
   py -m playwright install chromium
   ```

#### ② 設定ファイル（.env）の作成
1. ディレクトリ内にある `.env.template` ファイルをコピーして、名前を **`.env`** に変更します。
2. `.env` ファイルを「メモ帳」等で開き、控えておいたキーを貼り付けて保存します：
   ```env
   LINE_CHANNEL_ACCESS_TOKEN=あなたのMessaging APIアクセストークン
   LINE_CHANNEL_SECRET=あなたのチャネルシークレット
   PORT=5000
   ```

### 3. 対話型ボットのローカルテスト方法 (ngrok の利用)

LINEからタクミさんのPCへメッセージを届かせるために、無料のトンネルツール **`ngrok`** を使用します。

1. [ngrokの公式サイト](https://ngrok.com/)からツールを無料ダウンロードします。
2. ターミナルで以下のコマンドを実行し、ローカルの5000番ポートをインターネットに公開します：
   ```bash
   ngrok http 5000
   ```
3. 画面上に表示される `Forwarding` の `https://xxxx.ngrok-free.app` という **HTTPSのURL** をコピーします。
4. **LINE Developers** の「Messaging API設定」タブを開き、**「Webhook URL」** の入力欄にコピーしたURLを貼り付け、末尾に **/callback** を追加します：
   * 例: `https://xxxx.ngrok-free.app/callback`
5. 「検証 (Verify)」ボタンを押し、「Success」と表示されることを確認します。

### 🌟 重要：LINEグループID(groupId)の自動取得機能

本来、LINEのプッシュ通知をグループへ送信するためには、開発者しか見られない非常に複雑な「グループID (Ca1234...)」を調べる必要があります。
しかし、本システムには**「グループID自動キャッチ機能」**が搭載されています！

1. `line_bot.py` を起動して `ngrok` の連携が完了したら、ボットを招待したLINEグループで、**何か一言（例: 「こんにちは」「テスト」など）を発言**します。
2. ボットのプログラムがLINEからの発言を受け取った瞬間、**自動的にグループIDを認識し、ディレクトリ内に `group_id.txt` というファイルを作成してIDを自動保存**します！
3. これにより、これ以降に定期巡回コレクター (`main.py`) を実行した際、自動的にそのグループ宛てにマークアイドルの新着・セトリお礼プッシュ通知が届くようになります。

### 4. 実行方法

本システムは、**「対話待受サーバー」** と **「定期巡回コレクター」** の2つを起動して動作します。

#### ① 対話待受サーバーの起動 (常時起動)
別のターミナルウィンドウを開き、以下を実行してLINEからのつぶやきを受け取るサーバーを起動します：
```bash
cd C:\Users\takum\.gemini\antigravity\scratch\idol-event-collector
py line_bot.py
```
LINEグループ内で **「今日新潟で何かある？」** や **「7月12日東京である？」** と発言すると、ボットがSQLiteから検索し、即座にライブ情報を返信してくれます。

#### ② 定期巡回コレクターの実行 (1日5回の自動実行)
以下のスクリプトを呼び出すと、最新チケットサイトと公式Xからデータを収集し、新着本命アイドルを自動プッシュ通知しつつ、一般イベントをデータベースへ静かに蓄積します：
```bash
cd C:\Users\takum\.gemini\antigravity\scratch\idol-event-collector
py main.py
```
ローカルでの定期実行は、Windowsの「タスクスケジューラ」を利用して `py main.py` を呼び出すように設定するか、あるいはGitHub Actionsを利用してクラウドから完全無料実行させることができます。

## 🚀 クラウドでの完全無料・常時起動運用

パソコンの電源を切っていても、24時間完全自動・無料でシステムを維持させたい場合：

1. **定期巡回コレクターの配置**
   - リポジトリにコードをプッシュし、GitHub Secretsに各種トークンを登録することで、配置した **GitHub Actions ( workflows/run_collector.yml )** が、タクミさんが決めたゴールデンタイム（1日5回: 12:00, 15:00, 18:00, 21:00, 25:00 JST）に自動で巡回を代行します。
2. **対話待受サーバーの無料ホスティング**
   - 無料のクラウドサービスである **Render.com** や **Hugging Face Spaces** などに `line_bot.py` をデプロイします。
   - 無料枠で24時間起動させることができ、生成されたURLをLINE Webhookに設定すれば、PCの電源が切れていてもいつでもスマホのLINEに返答してくれるようになります。
